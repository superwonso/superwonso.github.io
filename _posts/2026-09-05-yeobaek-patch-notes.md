여백의 첫 패치노트다. 현재까지 반영하고 배포한 주요 기능과 확인한 범위를 짧게 정리한다.

[서비스 소개](/projects/yeobaek/) · [여백 열기](https://superwonso.github.io/stt_server_cdh/) · [상세 검증 기록](https://github.com/superwonso/stt_server_cdh/blob/main/HANDOFF.md)

## 사용하면서 달라지는 점

- **로그인 유지:** 같은 탭에서 새로고침해도 서버가 세션을 확인해 최대 24시간 범위에서 로그인을 복원한다. 로그아웃·만료·서버 주소 변경 시에는 다시 로그인한다. 마이크 녹음을 새로고침 후 자동으로 다시 시작하는 기능은 아니다.
- **수업 요약:** 종료된 수업에서 개요·핵심 내용·복습 질문을 만들고 Markdown으로 내려받는다. 원문과 별도로 보관한다.
- **영어 수업 번역:** 수업 전체에서 추린 문맥과 앞뒤 구간을 참고해 한국어로 번역한다. 문장별 원문 대조와 한국어 전체 보기는 같은 결과의 두 표시 방식이며, 각각 Markdown으로 내보낼 수 있다.
- **무음에도 계속 녹음:** 무음 자동 휴식은 넣지 않았다. 직접 누르는 일시정지·재개는 유지한다.
- **연결 복구 보강:** CLOVA 전송 응답을 잃으면 서버에 이미 저장된 결과를 먼저 확인한다. CLOVA의 처리 여부가 불명확한 음성은 자동으로 반복 전송하지 않으며, 해결되지 않은 조각은 기기에 남기고 확인을 요청한다. 로컬 Qwen은 같은 조각 ID로 안전하게 재시도하는 경로를 유지한다.
- **관리자 상태 확인:** 요약·번역 대기 작업도 관리자 화면의 작업 수에 포함한다. 개인 수업 본문을 관리자에게 보여 주기 위한 기능은 아니다.

## 녹음 보관 방식

완료된 녹음의 최종 저장소는 운영자의 Google Drive다. 사용자별 폴더로 옮겨 파일 검증을 마치면 서버의 WAV를 삭제해 디스크를 비운다. 녹음·업로드 중이거나 전송·검증·서버 사본 정리가 끝나지 않은 동안에는 서버에 임시 보관한다. 계정·텍스트 데이터베이스 백업과는 다른 역할이다.

## 확인한 것과 남은 것

배포 전 자동 테스트 **607개**를 통과했다. 공개 한국어 음성으로 Qwen과 CLOVA를 실행했고, CLOVA는 5분 미만 시험에서 연결 교체·강제 단절 뒤 재연결·종료 처리를 확인했다. 실제 NOVA API의 후보정·요약·영문 번역도 시험했다. 격리된 Chromium에서는 로그인 복원, 무음 녹음, 오프라인 대기열, 수동 일시정지·재개와 내보내기를 확인했다.

짧은 시험이 현장 무중단이나 누락·중복 없음을 보장하지는 않는다. Qwen은 이번 측정에서 입력보다 처리 시간이 길었고, CLOVA도 마지막 기준문이 완전히 일치한 것은 아니다. 실제 수업의 의미 정확도, 학교 Wi-Fi·태블릿·절전, 45~90분 연속 수업은 추가 검증이 필요하다.

이미 열어 둔 화면에서는 **녹음과 저장을 끝낸 뒤 새로고침**하면 새 기능을 사용할 수 있다. 마이크 기본 엔진은 CLOVA이며, 로컬 Qwen 선택과 기존 파일·공유 소리 변환도 유지한다.
