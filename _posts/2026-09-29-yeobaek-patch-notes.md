이번 글은 **9월 14일 패치노트 이후 서비스에 반영한 변경**을 정리한다. 가장 큰 변화는 **수업 정리본 하나에서 원문과 설명, 강의자료를 함께 보고 여러 회차를 묶어 복습할 수 있게 된 것**이다. 통합 정리·자료·복습 기능은 9월 26일 Windows 운영 서버와 웹에 적용했다.

## 후보정·요약·번역을 수업 정리본 하나로

여러 AI 도구를 각각 실행하던 흐름을 **수업 정리본 만들기** 하나로 모았다. 한국어 수업의 표현 정리, 영어 수업의 한국어 번역, 핵심 흐름과 상세 설명을 한 문서에서 읽고 Markdown으로 내려받을 수 있다. 한글로 받아쓴 영어 표현도 전체 문맥을 참고해 복원하며, 추정하거나 확인이 필요한 부분을 함께 표시한다.

짧은 개요만 남기면서 세부 내용을 잃지 않도록 **수업에 저장된 받아쓰기 원문의 모든 구간을 순서·시각·내용 그대로 상세 설명 아래에 보존**한다. 원문은 접어 두었다가 펼쳐 대조할 수 있다. 기존 후보정·요약·번역 결과도 지우지 않고 **이전 AI 결과**에서 계속 조회하고 내려받는다.

AI 응답의 형식이나 개요에 문제가 생겨도 사용할 수 있는 본문과 원문은 제공하고, 확인이 필요한 사항을 문서 하단에 짧게 알린다. 실제 통신·저장 실패와 권한 문제는 구분해 처리한다.

**원문 전체를 보존한다는 것과 AI 설명이 모든 의미를 정확히 옮겼다는 것은 다르다.** 받아쓰기 자체에서 놓친 소리를 되살리는 기능도 아니다. 중요한 용어·숫자·설명은 원문과 녹음을 함께 확인해야 한다.

## PDF·PPTX 강의자료를 정리본의 근거로

수업 화면의 **PDF · PPTX 강의자료**에서 파일을 올리고, **Markdown으로 변환**을 눌러 추출 내용을 확인할 수 있다. 자료 원본과 변환문을 내려받거나 삭제할 수 있으며, 페이지·슬라이드 위치를 남겨 정리본의 인용을 따라가 볼 수 있다.

- **개별 수업 자료:** 해당 회차를 정리할 때 참고한다.
- **강의 공통 자료:** 같은 강의로 연결한 여러 회차에서 함께 참고한다.
- **업로드와 변환:** 서버에서 문서의 텍스트를 추출하는 단계다. 이것만으로 유료 AI 생성을 시작하지 않는다.
- **정리본 생성:** 사용자가 생성을 요청하면 해당 자료의 추출문을 기존 NOVA AI 서비스에 보조 자료로 보낸다. 자료가 받아쓰기 원문을 대체하지는 않는다.

그림·스캔·복잡한 수식이나 도표를 모두 읽어 주는 OCR 기능은 아니다. 추출하지 못한 영역이나 읽기 순서가 불확실한 부분은 안내하므로, 변환문과 원본 자료를 먼저 확인하는 것이 좋다.

## 강의명과 실제 수업 일시를 나누고, 여러 회차 복습하기

**강의별 자료 · 복습**에서 강의를 만들고 기존 수업을 연결할 수 있다. 강의명, 회차 제목, 실제 수업 일시를 따로 기록한다. 기존 제목과 생성 시각을 추측해서 바꾸거나, 이름이 비슷하다는 이유만으로 수업을 자동 합치지는 않는다.

한 강의 안에서 지금까지의 수업과 자료를 모아 보고, **전체 수업 또는 선택한 회차**로 복습 정리본을 만들 수 있다. 회차별 개요를 모은 전체 핵심 흐름과 각 회차의 상세 내용·원문을 함께 제공하며, 결과를 저장하고 Markdown으로 내려받는다.

자료나 원문이 바뀌면 필요에 따라 다시 생성하도록 안내한다. 같은 모델·같은 범위·같은 내용으로 이미 완료한 결과는 재사용한다. 여러 회차를 새로 정리할 때는 분량에 따라 여러 번의 유료 AI 요청이 발생할 수 있으며, 강의를 열거나 자료를 올리는 것만으로 자동 생성하지 않는다.

### 처음 사용하는 순서

1. 녹음과 마지막 저장이 끝난 수업을 연다.
2. 필요하면 PDF·PPTX 자료를 업로드하고 Markdown 추출 내용을 확인한다.
3. **수업 정리본 만들기**로 해당 회차를 정리한다.
4. **강의별 자료 · 복습**에서 강의와 회차·일시를 연결한다.
5. 복습할 회차를 골라 누적 정리본 생성을 요청한다.

## 보관된 음성을 파일 변환으로 이어 가기

**보관 중 · 전송 보류한 수업**의 음성을 **녹음 파일 가져오기**로 보내 Qwen 파일 전사에 사용할 수 있다. 현재 녹음에서 CLOVA 처리 결과가 불확실해 멈춘 경우에도 녹음을 마무리해 보관한 뒤 이 흐름으로 이동할 수 있다. 파일을 준비하는 단계와 실제 업로드·변환 요청은 구분한다.

기기에 남아 있는 같은 수업의 WAV 조각은 겹침과 시간 위치를 확인해 하나의 변환용 파일로 준비할 수 있다. 남아 있는 조각 사이의 빈 구간은 시각을 유지하기 위한 무음으로 표시되며, 잃어버린 음성이 복원되는 것은 아니다. 이전 CLOVA 결과의 성공을 추정하지 않는다. **파일 변환은 새 수업 기록을 만들므로 기존의 부분 전사 기록과 별도로 확인**해야 한다.

파일 변환이 끝난 새 수업을 확인하면 **변환 성공 확인 · 보류 종료**를 선택할 수 있다. WAV를 직접 내려받아 저장·재생을 확인한 뒤 보류를 종료하는 방법도 유지한다. 보류 종료는 목록을 정리하는 동작이며, 기기 원본을 삭제하거나 기존 전사가 성공했다고 바꾸지 않는다.

원본 녹음 저장도 받아쓰기 처리와 분리했다. CLOVA 응답이 늦거나 처리 결과를 확인하지 못한 경우에도 원본 음성 업로드는 별도로 진행한다. **원본 저장 완료와 받아쓰기 완료는 서로 다른 상태**이며, 이미 처리됐는지 모르는 CLOVA 음성을 자동 반복 전송하지 않는 보호는 유지한다. 네트워크 단절이나 저장공간 부족 상황까지 서버 보관을 보장하는 것은 아니다.

## 언어 선택과 화면 정리

- 음성 인식 모델보다 **말하는 언어를 먼저 선택**한다. 영어·자동 감지는 Qwen을 기본으로 제안하고, 화면 이름은 **Qwen-3**으로 정리했다.
- Qwen의 **자동 감지 범위를 한국어·영어로 제한**했다. 다른 언어로 잘못 판정되는 상황을 줄이기 위한 변경이며, 발음이나 인식 결과의 정확성을 보장하는 설정은 아니다.
- 받아쓰기는 **문장 보기**를 기본으로 제공한다. 자동 따라가기는 전사 영역 안에서 동작하며, 이전 내용을 읽으려고 위로 이동하면 멈췄다가 다시 따라갈 수 있다.
- **녹음 상태 · 음성 보관**과 **보관 중 · 전송 보류한 수업**은 제목을 눌러 펼치고 접을 수 있으며 처음에는 접힌 상태다.
- 파일 변환을 취소하는 순간 상태 조회가 잠깐 404로 응답하던 문제도 수정했다.

## Windows 운영과 AI 모델 변경

Windows 네이티브 실행 경로를 추가하고 현재 서비스에 적용했다. API와 Qwen은 별도 프로세스로 유지하며 기존 Linux·ROCm 실행 지원도 남겨 두었다. 서비스 주소와 기존 계정·수업 데이터는 유지한다. 서비스가 실행되는 PC를 끄거나 절전으로 전환하면 정상적인 실시간 처리가 계속될 수 없다는 점은 같다.

AI 텍스트 처리에는 **NOVA를 통한 GPT-6 Luna**를 적용했다. 음성을 받아쓰는 Qwen과 역할이 다르며, 모델 이름이 바뀌었다는 이유만으로 모든 오류가 해결되거나 품질·속도가 항상 좋아졌다고 보지는 않는다.

## 확인한 범위와 남은 한계

9월 26일 통합 정리·자료·복습 릴리스 기준으로 다음을 확인했다.

- Python 자동 검사 **1,221개 통과**, 환경별 제외 **88개**. 제외한 검사는 통과 수에 넣지 않았다.
- JavaScript 자동 검사 **720개 통과**.
- 실제 Edge의 **1280px·390px 화면**에서 합성 수업·자료의 업로드, 변환, 원문·인용 표시와 복습 흐름 확인.
- 합성 수업·자료를 사용한 **NOVA GPT-6 Luna 호출 6회**. 초기 검증에서 발견한 개요 누락을 수정한 뒤 한국어·영어 결과에서 개요·자료 인용·원문 전체 보존 확인.
- 운영 적용 전후 기존 DB 값 보존, API 정상 응답, 인증 없는 접근 차단, 공개 웹 배포 파일 확인.

이 검증은 실제 사용자 수업·첨부문서, 긴 수업의 의미 정확도, 장시간 동시 사용, 실제 Linux·ROCm 기동을 모두 시험했다는 뜻은 아니다. 강의자료의 이미지·스캔 OCR도 이번 범위에 포함하지 않았다.

운영 백업에서는 **자료 원본 파일과 DB를 구분**해야 한다. 변환문과 정리본은 DB에 저장되지만, PDF·PPTX 원본은 기존 DB·설정 암호화 백업에 포함되지 않아 자료 폴더도 별도로 보존해야 한다.

자세한 사용법과 검증 범위는 [통합 정리·자료·복습 안내](https://github.com/superwonso/stt_server_cdh/blob/main/docs/unified-study-review.md), [보관 음성 사용 안내](https://github.com/superwonso/stt_server_cdh/blob/main/docs/held-recordings.md), [변경 기록](https://github.com/superwonso/stt_server_cdh/blob/main/HANDOFF.md)에 남겼다.

이미 열어 둔 화면은 **녹음·전송을 마치고 남은 음성의 저장을 확인한 뒤 새로고침**하면 된다. 메모리에만 남아 있다는 경고가 있다면 먼저 음성을 확보하고, 다음 수업을 시작하기 전에 새 화면을 열자.
