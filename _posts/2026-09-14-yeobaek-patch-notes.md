이번 글은 **9월 13일 서비스에 반영한 화면 개선과 API·로컬 음성 모델 분리**, 그리고 지난 패치노트 이후 보완한 새 수업 시작 흐름을 정리한다. 작은 창에서도 안내와 버튼을 읽기 쉽게 만들고, 로컬 모델의 준비가 로그인과 기록 조회까지 기다리게 하던 구조를 바꿨다. 웹 배포와 서버 반영을 마쳤다.

[여백 열기](https://superwonso.github.io/stt_server_cdh/) · [서비스 소개](/projects/yeobaek/) · [이전 패치노트](/projects/yeobaek/updates/2026-09-10/)

## 작은 화면에서 덜 답답하게

- 좁은 창에서 제목이나 버튼 글자가 한 글자씩 세로로 쌓이던 배치를 수정했다. 제목과 작업 버튼, 오류 설명과 복구 버튼이 서로의 공간을 과하게 줄이지 않도록 나눴다.
- 화면 폭에 맞춰 설정 항목과 녹음·파일 입력 버튼을 재배치하고, 좁은 화면에서는 복구 버튼을 한 줄씩 표시한다.
- **현재 입력 상태와 기기에 남은 음성 안내**를 하나의 복구 영역으로 묶었다. 주변 화면과 여백·글자 크기·배경·테두리를 맞추되, 실제 입력 중단 경고는 구분되게 유지했다.
- 번역·요약·수업 정리본의 본문과 안내 스타일을 정돈하고, 긴 문구와 대화창의 줄바꿈·스크롤을 보완했다.

중요한 경고나 다운로드 기능을 숨긴 변경은 아니다. 화면을 정돈한 부분에서는 기존 녹음·저장·전송 동작을 그대로 유지했다.

## 이전 음성을 보관하고 새 수업 시작하기

음성을 내려받았는데도 이전 전송 오류가 남아 새 수업을 시작하기 어려운 흐름을 보완했다. **기존 음성 보관 · 새 수업**을 누르면 기존 녹음을 마무리해 기기에 저장하고, 기존 전송 대상 수업들의 음성은 남긴 채 전송만 보류한 뒤 새 수업 화면으로 이동한다. 새 수업은 사용자가 받아쓰기 시작 버튼을 눌러 별도로 녹음한다.

보류한 음성을 삭제하거나 전송 성공으로 처리하지는 않는다. 남겨 둔 수업은 나중에 다운로드하거나 전송 복구를 선택할 수 있다. 다운로드는 복사본을 받는 동작이므로, 파일을 받았다는 이유만으로 기존 음성을 자동 정리하지 않는다.

다만 기기 저장에 실패해 **메모리(RAM)에만 남은 음성**이 있거나 다른 탭의 녹음 상태를 안전하게 확인할 수 없다면 새 녹음이 제한될 수 있다. 이때는 음성을 확보하기 전에 원래 탭을 닫거나 새로고침하지 말자.

## 로컬 모델을 재시작해도 로그인과 기록 조회는 유지

같은 컴퓨터 안에서 서버를 두 프로세스로 나눴다.

- **API 서버:** 로그인·권한 검사·수업 관리·녹음 보관, CLOVA와 AI 기능을 담당한다.
- **로컬 모델 서버:** 기존 Qwen과 음성·텍스트의 시각을 맞추는 정렬기를 실행한다.

이제 API가 켜져 있으면 Qwen을 준비하거나 모델만 재시작하는 동안에도 로그인·기존 기록 조회·CLOVA를 이용할 수 있다. 화면과 관리자 페이지에서도 API의 연결 상태와 로컬 모델의 준비 상태를 구분해 안내한다. 두 프로세스는 컴퓨터 내부의 비공개 연결로 통신하며, 모델 서버에 계정이나 클라우드 API 키를 넘기지 않는다.

**컴퓨터 자체를 끄면 서비스도 중단된다.** 다른 컴퓨터나 상시 가동 클라우드로 옮긴 것은 아니므로 PC 전원·WSL·인터넷 장애까지 분리한 것은 아니다. API 자체를 재시작하는 동안에도 접속이 계속된다는 의미는 아니다.

## Qwen 연결이 끊겼을 때 남은 작업 보존

로컬 모델의 준비·연결 단절·응답 지연으로 처리가 끝나지 못하면 같은 음성 조각 ID와 마지막으로 저장한 경계 문맥을 사용해 재시도한다. 파일 변환도 업로드 원본과 처리된 부분을 남겨 두고 모델 연결을 기다리며, 연결되면 이어서 처리한다. 마지막 구간 저장과 중복 요청 처리도 이 분리 구조에 맞춰 확인했다.

이 정책을 모든 오류에 적용하는 것은 아니다. **CLOVA가 이미 처리했는지 불확실한 음성은 자동으로 반복 전송하지 않는다.** 저장장치 오류 역시 모델 연결 대기와 구분한다. 파일 변환을 사용자가 명시적으로 취소하면 기존 취소 정책에 따라 업로드 원본과 부분 변환이 정리된다.

## 바뀌지 않은 것과 확인한 범위

음성 인식 모델은 교체하지 않았다. 마이크의 기본 선택은 CLOVA로 유지하며, 로컬 Qwen 선택과 기존 파일·공유 소리 변환도 유지한다. 서비스 주소·계정·수업 기록·Google Drive 녹음 보관 방식은 그대로다. 이번 분리 자체를 인식 정확도나 처리 속도 향상으로 보지는 않는다.

최종 자동 회귀 테스트 **1,437개**를 통과했다. 화면 개선은 별도로 여러 화면 폭과 상태를 조합한 **72개 레이아웃 점검**을 했고, 모델 분리는 공개 한국어 음성 **4.8초**로 실제 전사·마지막 저장·같은 조각 재요청의 중복 방지를 확인했다. 모델이 꺼진 상태의 API 응답과 접근 차단, 운영 데이터 보존, 공개 웹 배포본도 확인했다.

짧은 표본과 자동 테스트가 모든 수업 환경을 보장하지는 않는다. 수시간 연속 수업, 학교 Wi-Fi, 실물 태블릿·절전, 동시 실사용과 장시간 GPU 메모리 증가는 이번 검증 범위 밖이다. 자세한 결과는 [변경·검증 기록](https://github.com/superwonso/stt_server_cdh/blob/main/HANDOFF.md)에 남겼다.

이미 열어 둔 화면에는 **녹음·전송을 마치고, 남은 음성의 저장과 필요 시 다운로드를 확인한 뒤 새로고침**하면 새 화면이 적용된다. 내려받은 파일의 크기·길이·재생으로 필요한 음성이 들어 있는지도 확인하자. 전송 오류나 메모리에만 음성이 남았다는 경고가 있다면 먼저 음성을 확보해야 한다.
