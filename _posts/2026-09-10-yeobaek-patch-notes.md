이번 업데이트는 **문제가 생겨도 이미 받은 기록을 꺼낼 수 있게 하는 것**에 초점을 맞췄다. 녹음 복구와 내보내기를 보강하고, 기존 후보정·번역과 별도로 수업 전체 문맥을 참고하는 한국어 정리본을 추가했다. 웹과 API 서버에 반영을 마쳤다.

[여백 열기](https://superwonso.github.io/stt_server_cdh/) · [서비스 소개](/projects/yeobaek/) · [이전 패치노트](/projects/yeobaek/updates/2026-09-05/)

## 중단 뒤에도 텍스트와 음성 내려받기

- **TXT·Markdown:** 전송 오류나 일시정지 중에도 화면에 받은 내용을 저장할 수 있다. 다른 수업을 녹음하는 동안 지난 수업을 내려받는 것도 가능하다. 미완료 수업은 저장 시점의 부분 기록임을 표시한다.
- **기기에 남은 음성:** 첫 실패 조각 하나뿐 아니라 뒤에 쌓인 음성과 받은 상태로 남아 있는 미완성 끝부분도 내려받는다. 일치하는 겹침은 한 번만 담고, 없는 구간은 별도 파일로 나눠 표시한다. 원본이나 전송 대기열을 삭제하지 않는다.
- **서버에 저장된 부분 WAV:** 아직 끝나지 않은 수업도 서버가 이미 보관한 구간을 요청 시점의 길이로 받을 수 있다. 다운로드를 위해 녹음을 종료하거나 수업 저장을 강제로 마무리하지 않는다.

기기 파일과 서버 부분 WAV는 **서로 다른 범위**다. 기기에만 남은 미전송 음성은 서버 파일에 없고, 서버 전송이 확인돼 기기에서 정리된 앞부분은 기기 파일에 없을 수 있다. 두 파일이 자동으로 합쳐지지는 않으며, 서버에 음성이 있다는 것이 받아쓰기까지 성공했다는 뜻도 아니다. 내려받은 파일의 크기·길이·재생을 확인해 두는 것이 좋다.

## 원래 탭을 유지하는 별도 구조 창

[음성 구조 창](https://superwonso.github.io/stt_server_cdh/rescue.html)을 **같은 브라우저·프로필의 별도 탭**으로 열어, 로그인한 계정의 브라우저 저장소에 남은 음성을 확인할 수 있다. 원래 탭의 녹음·전송 상태는 바꾸지 않는다.

**음성을 확보하기 전에 기존 탭을 새로고침하거나 닫지 말자.** 별도 창은 원래 탭의 메모리(RAM)에만 남은 음성을 읽을 수 없고, 브라우저 저장소에도 없는 소리를 복원하지는 못한다. 구조 창에서 새로 로그인하려면 서버도 켜져 있어야 한다.

## 입력 상태 구분과 이어 녹음

전송 실패와 실제 마이크 입력 중단을 구분해 안내한다. 조용한 음성도 정상 입력으로 취급하며, 실제 입력이 끊겼다면 복구·다시 연결을 안내한다. 브라우저나 OS가 입력을 중단한 동안의 소리를 나중에 되살리는 기능은 아니다.

- **현재 녹음이 살아 있다면:** 기존 일시정지·재개 또는 입력 재연결을 사용한다.
- **녹음이 완전히 끝났다면:** **이어 녹음**으로 원래 수업과 연결된 새 기록을 시작한다. 원본 텍스트·WAV·AI 결과는 보존한다. 원본 WAV에 이어 붙이는 방식은 아니며, 이전 미전송 음성도 별도로 해결해야 한다.

## 원문 전체 문맥으로 만드는 수업 정리본

기존 후보정과 문장별 번역은 그대로 유지한다. 새 **수업 정리본**은 후보정·번역·직접 수정을 거치지 않은 **확정된 받아쓰기 원문 전체**에서 출발한다. 서버가 이를 하나의 Markdown 자료로 구성하므로 원문 파일을 따로 만들어 올릴 필요는 없다.

다음 요청을 프롬프트에 반영했다.

> 전체적인 맥락을 고려해서 영어로 작성되어 있는 것들을 한글로 번역해줘. 영어인데 한글로 써져있는 것들도 있으니 이것도 해결해주면 좋을거같아

영어 문장과 한글로 받아쓴 영어 음차를 전체 문맥에 맞게 한국어로 풀어 쓰고, 인접한 내용을 주제별 문단으로 정돈한다. 복원한 표현과 확인이 필요한 부분, 원문 위치를 함께 남기고 **정리본 Markdown 한 파일**로 내려받는다. 기존 원문·AI 결과·필기는 덮어쓰지 않으며, 다른 수업의 녹음을 중단하지 않는다.

긴 결과는 같은 전체 원문을 참고하면서 나눠 생성한다. Markdown이라는 형식 자체가 정확도를 보장하지는 않는다. 의미나 용어를 잘못 복원할 수 있으므로 중요한 내용은 원문·녹음과 대조해야 한다.

## 그 밖의 개선과 확인 범위

- 녹음 파일 **드래그 앤 드롭**을 추가했다. 파일을 놓으면 선택만 되고, 확인 후 변환 버튼을 눌러야 업로드한다.
- AI의 잘린 응답·거절·형식 오류를 구분하고, 숫자 등을 보호하는 과정에서 정상 후보정 결과까지 거절하던 길이 검사를 보완했다. 원문·숫자 보호 검사는 유지한다.
- 이번 업데이트에서 음성 인식과 AI 모델을 교체하지는 않았다.

자동 회귀 테스트 **1,341개**, 격리된 실제 Chromium의 복구·이어 녹음·다운로드 시험, 공개 PC·모바일 폭의 화면 확인을 마쳤다. 정리본은 실제 NOVA API로 짧은 비개인 예문 두 개를 확인했다. 실사용에서도 자기 기록의 다운로드 문제가 해결됐다는 피드백을 받았다.

다만 특정 사례의 해결을 모든 환경의 복구 보장으로 볼 수는 없다. 이번 검증은 실제 학교 Wi-Fi·태블릿·절전 상황이나 45~90분 수업의 무중단 동작, 긴 수업 정리본의 의미 정확도를 확인한 것은 아니다. 자세한 범위는 [변경·검증 기록](https://github.com/superwonso/stt_server_cdh/blob/main/HANDOFF.md)과 [정리본 안내](https://github.com/superwonso/stt_server_cdh/blob/main/docs/study-notes.md)에 남겼다.
